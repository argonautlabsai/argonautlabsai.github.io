Run Kimi K3.1 Pro
on one GPU.

Argodrive DS4 Kimi K3.1 is our integrated inference engine: the Kimi port, expert caches and NVMe streaming are already included. Built on Salvatore Sanfilippo’s ds4. 3.05 tok/s decode on raw completions with its Qwen drafter, measured on one 96 GB RTX PRO 6000 Blackwell, with the same tokens as plain decoding. Prompt processing (prefill) reaches 43 tok/s on a 1,512-token prompt, and K3.1’s sparse attention runs contexts up to 16,384 tokens.

KIMI K3.1 PRO / ARGODRIVE-DS4

3.05 tok/s.
One 96 GB GPU.

With its Qwen drafter, Kimi K3.1 Pro decodes raw completions at 3.05 tok/s on one RTX PRO 6000 Blackwell, with the same tokens as plain decoding. The prompt pass reads most of the model once, so long prompts go fastest: up to 43 tok/s. Chat runs at about 2 tok/s, and K3.1’s sparse attention takes contexts up to 16,384 tokens.

Decode is greedy, on raw completions of “The three main financial statements are”, with the same tokens as plain decoding: the logits of 3,800 positions showed no differing bit. One RTX PRO 6000 Blackwell (96 GB) in a 70 GiB VM; the experts stream from a RAID0 of three NVMe drives, a second NVMe and a Thunderbolt NVMe. No expert skipping. Since 8 November the code includes K3.1’s sparse attention (the DSA indexer), measured at 4k, 8k and 16k tokens: a 6,769-token prompt takes 60 s and then decodes at 1.51 tok/s. The spine’s activations are fp32. Equivalence to Moonshot’s reference implementation has not been validated.

DEEPSEEK V4.1 FLASH Q4 / DS4

Prefill was reading one drive.
And twice the bytes.

A 518 GB model streamed from NVMe on a 128 GB laptop. Prefill went through the memory map of the primary file, so one drive moved 315.9 GB while the others sat idle — and the layer-major sweep read all 384 experts per layer where the prompt routes to 187. Staging every layer through the weighted split read, then reading only the selected experts. Measured against the pinned upstream binary with a byte-identical output hash on every arm.

The 30 September read-ahead staging plus a continuous prefill reader, Engram row-table reads on upstream’s prefetch thread from the first layer, and a conditional read-ahead prior (how often an expert at one layer followed each expert of the previous layer in 19 other prompts, applied to this prompt’s own routing). 05 / ARGONAUT LABS

Independent research.
Work you can inspect.

We investigate storage, memory and scheduling for large-model inference on local hardware. Argodrive grew out of these experiments: a way to see the bottlenecks, compare changes and keep the evidence.

Our work builds on Salvatore Sanfilippo’s ds4 and gavamedia’s deltafin, and the wider llama.cpp and GGML ecosystem. Development and review use Claude, ChatGPT and OpenAI Codex, with human direction and measured validation.
